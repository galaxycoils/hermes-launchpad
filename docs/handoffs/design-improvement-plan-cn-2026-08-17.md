# 设计方案：Hermes Launchpad — UI/UX 设计改进

## 设计理念

**核心原则**：从"功能可用"升级到"体验愉悦"。参考 Material Design 3、Ant Design 5 和 pump.fun 的交互模式，打造专业的去中心化交易界面。

## 当前问题诊断

| 组件 | 问题 | 影响 |
|------|------|------|
| TokenCard | 4个badge堆叠、进度条太小、lore与指标争夺注意力 | 信息过载，用户难以快速扫描 |
| TradePanel | 输入框朴素、没有实时报价动画、价格冲击无颜色提示 | 交易决策缺乏视觉反馈 |
| Hero | 硬编码"INDEX API REACHABLE"、无实际健康检查 | 误导用户 |
| TopNav | 无余额显示、无网络标识、钱包菜单简陋 | 用户无法快速确认连接状态 |
| 空状态 | 纯文本、无情感化设计 | 用户感到无聊 |
| 微交互 | 仅hover缩放、无数字动画、无过渡 | 界面感觉生硬 |

---

## 设计方案 D1: TokenCard 信息层级重构

**当前问题**: 4个badge同时显示、进度条被挤压、lore强制显示。

**解决方案**:
```
┌─────────────────────────────────────┐
│  🚀 Galactic Gecko  $GECKO     [🟢]│  ← 主行: emoji + 名称 + 单badge
│  by 0x7a3b...9f2e                   │  ← 次行: 创作者(低对比度)
│  ─────────────────────────────────  │
│  SOL raised          Curve          │
│  ██░░░░░░░ 12.5     14.7%          │  ← 指标行: 左数值 + 右进度
│  ─────────────────────────────────  │
│  "Lore italic..."            [展开] │  ← lore折叠,可展开
└─────────────────────────────────────┘
```

**设计原则**:
- **信息层级**: 名称(bold) → 创作者(50%透明度) → 指标(等宽字体)
- **单一badge**: 只显示最高优先级状态 (Demo/Live/Ready/On-chain)
- **进度条全宽**: 使用 `h-2` 高度 + 渐变填充，>75%时添加发光效果
- **lore折叠**: 默认隐藏, 点击展开, 节省空间

## 设计方案 D2: TradePanel 视觉反馈

**当前问题**: 买卖切换无视觉确认、报价突然出现、价格冲击无颜色编码。

**解决方案**:
- **买卖切换**: 胶囊式按钮带颜色填充动画 (绿色=买, 红色=卖)
- **金额输入**: 大字号占位符"0.00" + 实时报价下方显示
- **报价卡片**: 使用 `gsap.from()` slideDown 200ms 平滑出现
- **执行按钮**: 颜色过渡 + hover时 `scale(1.02)` 脉冲
- **价格冲击**: 颜色渐变 (<3%绿色, 3-5%黄色, >5%红色)

## 设计方案 D3: Hero 健康状态实时化

**当前问题**: 硬编码"INDEX API REACHABLE"。

**解决方案**:
- 接受 `live` prop 从父组件
- 颜色编码: 绿色(活跃)、黄色(降级)、红色(离线)
- 脉冲点动画
- 文案: "Live — Indexed" / "Degraded — Catching up" / "Offline"

## 设计方案 D4: 空状态情感化设计

**当前问题**: 纯文本"No tokens match"。

**解决方案**:
- 大emoji/插画 (64px) + 浮动动画
- 清晰主文案 + 次要提示
- 可选CTA按钮 "Launch the first token"
- 加载态使用 Skeleton 闪烁 (已实现,保持)

## 设计方案 D5: TopNav 余额与网络标识

**当前问题**: 无SOL余额、无网络标识、钱包菜单简陋。

**解决方案**:
- 连接后: 显示截断地址 + 余额内联
- 网络badge: Devnet 紫色标签
- 钱包菜单: 添加 "View on Solscan" 链接、复制地址、断开
- Avatar: 从钱包地址生成渐变 (已实现,保持)

## 设计方案 D6: 全局微交互

**当前问题**: 仅hover缩放、无数字动画、无过渡。

**解决方案**:
- 按钮hover: `active:scale-[0.97]` (已存在,标准化)
- 卡片hover: `hover:-translate-y-1` + 阴影 (已存在,增强)
- 数字变化: CountUp 动画 (SOL raised, XP gains)
- Tab切换: 淡入淡出,非突兀切换
- Modal打开: 背景淡入 + content scale from 0.95
- 交易成功: 彩纸效果 (已实现,保持)

## 设计方案 D7: 响应式优化

**当前问题**: 移动端体验未完全优化。

**解决方案**:
- 移动端: TradePanel 变为底部抽屉
- 移动端: TokenCard 网格 1列(<640px), 2列(tablet)
- 移动端: Hero 文字缩小 (已有 `sm:` 响应式)
- 移动端: BottomTabBar 已有,确保 safe-area-inset
