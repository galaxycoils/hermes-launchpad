## 5. Key Decisions & Rationale
- **Inlined Profile in `Home.tsx`:** `App.tsx` routes both `/` and `/profile` to `<Home />` (controlling `initialTab="profile"`). `src/pages/Profile.tsx` was dead code and was deleted to prevent divergent state.
- **Client-Side Trade Math & Slippage:** `useTrade.ts` leverages `computeBuyQuote` / `computeSellQuote` from `src/lib/solana.ts` and delegates signing directly to `window.solana` (Phantom/Solflare) via `sendTx`.
- **BroadcastChannel Guards:** Used `BroadcastChannel('hermes-graduation')` and `BroadcastChannel('hermes-reengagement')` combined with `localStorage` flags to prevent duplicate celebration modals across multiple open browser tabs.
- **Removed Fake Fallbacks:** Production read paths no longer fall back to hardcoded mock tokens, ensuring all display data reflects genuine indexed on-chain state.
- **Web3 Auth for Social Actions:** Comments and likes now require a signed challenge (`signMessage`) to prevent wallet address spoofing. Worker uses `tweetnacl` for Ed25519 signature verification.
- **Focus Traps:** `focus-trap-react` wraps modal content to trap keyboard focus, satisfying WCAG 2.4.3 Focus Order requirements.
- **Leaderboard State Distinction:** `ranksLive` boolean differentiates fetch failure (yellow warning) from empty data (subtle "No trades yet").
- **Quest Toast Fix:** Reading `result.questCompleted` directly from `indexTrade` response prevents re-triggering already-completed quests on subsequent trades.
